PUBLIC ENQUIRY FORMS

Three separate public forms

Each form is a standalone page that anyone can open without signing in. Every submission is validated by the server and saved as a lead in the CRM database; it then appears in the matching leads list.

Where these leads come from

CRM forms vs. the main website

  • CRM form submissions are stored with source crm_customer_form, crm_developer_form or crm_broker_form.
  • Enquiries from the main Compare Projects website are written by the website's own backend and are only visible here once this CRM points at the same database.
  • The same person submitting the same form for the same property within 24 hours is treated as a duplicate and not stored twice.
